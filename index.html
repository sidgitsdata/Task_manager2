Privacy Policy

Student Task Manager is an offline, client-side educational productivity tool.

Local Data Storage

All your task titles, subject names, due dates, and completion statuses are stored directly inside your own web browser using standard browser localStorage.

No Accounts & No Tracking

This application does not require any account creation or login. We do not use cookies, external analytics, tracking scripts, or remote database servers.

Data Control

Your task information never leaves your personal device. If you clear your browser browsing data or website storage for this page, all tasks will be deleted locally.

Terms and Conditions

Welcome to the Student Task Manager application. By using this tool, you agree to these simple terms.

Intended Use

This tool is designed for individual students to organize their personal assignments, study schedules, and project deadlines.

Data Responsibility

Because this application operates entirely in your local browser without a cloud backend, you are responsible for maintaining any critical academic records. We recommend checking off tasks as you finish them.

Free to Use

This software is provided freely as an educational project. There are no fees or subscriptions required to use this application.
